🔎 Binary Search

Halve the search range on every step — O(log n) on a sorted array

How it works: The array must be sorted. Compare the target with the middle element: if it matches, done; if the target is smaller, discard the right half; if larger, discard the left half. Repeat until found or the range is empty. Time Complexity: O(log n) — doubling the input adds just one more step.
