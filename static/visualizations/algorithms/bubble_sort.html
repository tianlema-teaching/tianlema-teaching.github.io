🫧 Bubble Sort

How It Works

Bubble Sort repeatedly steps through the list, comparing adjacent pairs and swapping them if they are in the wrong order. After each pass, the largest unsorted element "bubbles up" to its final position at the end. If a full pass makes no swaps, the array is already sorted and we stop early.

BUBBLE-SORT(A):
    for i = 1 to n - 1:
        swapped = false
        for j = 1 to n - i:
            if A[j] > A[j+1]:
                swap A[j], A[j+1]; swapped = true
        if not swapped: break

Complexity Analysis

Time Complexity:

  • Best Case: O(n) — Array is already sorted (one pass, no swaps)
  • Average Case: O(n²)
  • Worst Case: O(n²) — Array is reverse sorted

Space Complexity: O(1) — In-place sorting

Stable: Yes — Equal elements maintain their relative order
