👆 Selection Sort

How It Works

Selection Sort divides the array into a sorted part (left) and an unsorted part (right). In each pass it scans the unsorted part to find the minimum element, then swaps it into place at the front of the unsorted part. Unlike Bubble and Insertion Sort, it always performs the same number of comparisons regardless of the input order.

SELECTION-SORT(A):
    for i = 1 to n - 1:
        min = i
        for j = i + 1 to n:
            if A[j] < A[min]: min = j
        swap A[i], A[min]

Complexity Analysis

Time Complexity:

  • Best Case: O(n²) — Still scans everything, even if sorted
  • Average Case: O(n²)
  • Worst Case: O(n²)

Space Complexity: O(1) — In-place sorting

Stable: No — Swapping can reorder equal elements
