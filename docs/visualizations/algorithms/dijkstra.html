🛤️ Dijkstra's Shortest Path Algorithm

How It Works

Dijkstra finds the shortest path from a source to all other vertices (all edge weights must be non-negative):

  1. Initialize distances: source = 0, all others = ∞
  2. Extract vertex u with minimum distance from priority queue
  3. Relax each edge (u,v) leaving u: if d[u] + weight(u,v) < d[v], update d[v] and add v to the queue
  4. Repeat until all vertices are processed
