⚡ Quicksort Partition (Hoare)

Hoare Partition Scheme: Pivot is the first element

How Partition Works: Two pointers move toward each other. Pointer i moves right while elements are < pivot; pointer j moves left while elements are > pivot. When both stop and i < j, swap them and repeat. When i ≥ j (the pointers have met or crossed), return j as the split point, with A[lo..j] ≤ pivot and A[j+1..hi] ≥ pivot (quicksort then recurses on both parts). Unlike Lomuto, the pivot is not necessarily in its final position.
